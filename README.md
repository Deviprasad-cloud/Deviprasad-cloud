## Featured Projects

### Static Portfolio on S3 + CloudFront
[Live site](https://d27uhqlte1g5pd.cloudfront.net/) · [Repository](https://github.com/Deviprasad-cloud/portfolio)

```
GitHub ──► CodeBuild ──► S3 (private) ◄── CloudFront (HTTPS, OAC) ◄── Users
```
